Все MP3 входят в единый пул. При принятом событии столкновения, слияния или «Супергава» выбирать один случайный клип из **всех доступных MP3** с равной вероятностью `1/N` (сейчас N=11). Каждый файл доступен для каждого типа события. Повторы подряд допустимы. Список файлов брать из `clips` в [manifest.json](../public/assets/sfx/manifest.json), без жёстко заданного числа два; при добавлении MP3 обновлять manifest. Ошибочно не декодированные файлы исключать из доступного пула.

Настройки воспроизведения и SHA-256 исходников находятся в manifest. Правила отбора событий, приоритеты, лимит одновременных голосов, громкость, отключение и мобильное воспроизведение: [ТЗ, раздел 7](MVP_SPEC.md#7-звуки). Количество одновременно играющих голосов (два) не ограничивает число файлов в случайном пуле.

Файлы подключены в `src/audio/sound.ts`: весь пул manifest доступен для случайного воспроизведения при столкновениях и слияниях. Пути при загрузке строить относительно базового URL приложения для GitHub Pages `/sobakes_budkes/`.
