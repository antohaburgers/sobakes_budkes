# Звуки игры

Два MP3 предоставлены пользователем для «Собакес Будкес». Скопированы без перекодирования и изменения содержимого.

| Файл | Длительность | Формат | Размер |
|---|---:|---|---:|
| `public/assets/sfx/myinstants.mp3` | 1,254 с | MP3, 44,1 кГц, стерео | 51 347 байт |
| `public/assets/sfx/myinstants1.mp3` | 1,698 с | MP3, 44,1 кГц, стерео | 28 588 байт |

Оба звука используются в общем пуле: при достаточно сильном столкновении или подтверждённом слиянии выбирается один случайный клип с вероятностью 50%. Рядом могут случайно повториться одинаковые клипы. Настройки и SHA-256 исходников: [manifest.json](../public/assets/sfx/manifest.json).

Правила отбора событий, приоритеты, лимит одновременных голосов, громкость, отключение и ограничения мобильного воспроизведения: [ТЗ, раздел 7](MVP_SPEC.md#7-звуки).

Файлы включены в репозиторий; воспроизведение предстоит реализовать в коде игры. Пути при загрузке строить относительно базового URL приложения, чтобы работал GitHub Pages `/sobakes_budkes/`.
