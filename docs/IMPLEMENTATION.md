# Реализация MVP

Стек: TypeScript, Vite, Phaser 3 (отрисовка и ввод), Matter.js (самостоятельный фиксированный шаг физики). Автоматическое Phaser Matter-обновление не включено: физику ведёт `GameModel`, чтобы одну и ту же логику проверять без браузера.

`src/game/model.ts` хранит состояние партии, очередь появления, parent-ID тел, атомарные слияния, счёт и общий таймер переполнения. Визуальные эффекты и аудио подписаны на подтверждённые события. Части одного тела дедуплицируются; конечные слияния обрабатываются с приоритетом.

`src/config/colliders.json` содержит отдельные составные формы: упрощённые выпуклые оболочки полос alpha-силуэта каждого мастер-файла. Промежутки между лапами местами сглажены. Масштаб рассчитывается по площади для возрастающих уровней; смещение рисунка относительно центра масс вычисляется по геометрии. Текстуры не растягиваются и не обрезаются.

`src/audio/sound.ts` читает полный MP3 manifest, декодирует доступные клипы, выбирает случайный с равными шансами, ограничивает глобальную частоту и повтор одной пары. Длинные клипы не обрезаются по длине файла, но старый голос плавно завершается, если при слиянии заняты оба голоса. Пауза, mute и рестарт отменяют отложенное воспроизведение. Файлы не перекодировались.

Настройки ТЗ применены как стартовый баланс: эквивалентный диаметр 30×1.18^(level−1), restitution 0.08, friction 0.35. Форма влияет на укладку. Дальнейший плейтест может менять размеры и ощущение веса без изменения правил.

Доступен единый статический билд `dist/`. Ресурсы загружаются относительно базового пути Vite; PNG-мастера не включаются в браузерный пакет. Dev-only hook `window.__sobakes` предназначен для локальной отладки и исключается из production.

Проверки: `npm test`, TypeScript и production build; ручной проход в Chromium (старт, сброс, первое слияние, сохранение рекорда, пауза, подтверждение рестарта и mute). Мобильная вёрстка предусмотрена; Safari на физическом iPhone нужно дополнительно проверить реальным плейтестом.
